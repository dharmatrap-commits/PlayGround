# Valley of Stone

A small, self-contained top-down open-world adventure. Explore the village, Whisperwood forest, and the cave mouth, then help Elder Rowan defend the valley from the Hollow Warden. The game uses procedural 2D art and synthesized audio; it has no external assets or build step.

## Play

Serve the files over a local web server (ES modules do not run from `file://`) and open the page in a modern browser. For example:

```sh
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Controls

**Desktop**
- `WASD` or arrow keys — move
- Mouse — aim; hold the left mouse button — hurl stones
- `Space` — Stoneburst
- `E` — interact with people, signs, and the shrine; advance dialogue
- `Esc` or `P` — pause/resume; `M` — mute

**Phone / touch**
- Drag the left-side joystick — move
- Drag on the right half of the playfield — aim and release to throw; alternatively, hold **HURL** for auto-aim
- Tap **BURST** — Stoneburst
- Tap the on-screen interaction prompt near people or objects; tap dialogue to advance
- Use the pause and sound buttons in the HUD as needed

## Quest

Speak with Elder Rowan, defeat eight gloomlings in the Whisperwood, return for the reward, then defeat the Hollow Warden and report back. The cave is represented as an outdoor arena at its entrance rather than a separate dungeon.
